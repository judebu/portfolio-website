Atlas — AI-Powered Data Center Site Selection

View Project
Type:
Full-Stack Web Application
Focus:
Geospatial Analysis & AI-Assisted Site Selection

Atlas is an AI-powered data center site selection platform built with Next.js, TypeScript, Python, MapLibre, and deck.gl. Its interactive 3D map of Massachusetts helps users evaluate potential sites based on power infrastructure, land availability, construction costs, and environmental impact.

The platform integrates geospatial and environmental datasets with the Claude API through AWS Bedrock to compare locations, assess infrastructure feasibility and community impact, and recommend optimal sites for data center development.

MatchIQ — Sports Prediction Web App

View Project
Created By:
Jude Hosmer
Type:
Full-Stack Web Application

MatchIQ is a full-stack sports prediction app built with Next.js, TypeScript, FastAPI, and PostgreSQL. It combines Elo ratings, expected goals (xG), Poisson models, and Monte Carlo simulations to predict match outcomes.

A historical match data pipeline built with Pandas and SQLAlchemy cleans datasets, removes duplicates, and calculates Elo ratings to support the prediction models.

Google OAuth authentication through NextAuth gives users access to a PostgreSQL-backed profit tracker, where they can record daily betting results and monitor performance over time.

FilmFlow is a responsive movie discovery app built with React/Next.js and Tailwind for my CS391 Final Project at Boston University. It uses the TMDB API to power search, trending films and user watchlists, with Google Authentication for secure user accounts and MongoDB for data storage.
